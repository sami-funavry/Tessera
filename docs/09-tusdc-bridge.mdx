# Reference App — tUSDC Bridge

The tUSDC bridge is Tessera's reference application. It demonstrates the full cross-chain lifecycle — both directions — using a custom ERC20/CW20 test token. It is not real USDC.

The bridge exists to prove that the Tessera infrastructure works end-to-end. Every piece of the system is exercised: proof fetch, transformation, on-chain verification, `IApp` dispatch, economic enforcement.

---

## What It Demonstrates

| Capability | Demonstrated by |
|-----------|----------------|
| EVM → Cosmos asset transfer | Sepolia lock → Neutron mint |
| Cosmos → EVM asset transfer | Neutron burn → Sepolia release |
| Fraud prevention | S-2: challenger catches lying relayer |
| Liveness enforcement | S-3: successor submits; original slashed |
| Frivolous challenge prevention | S-4: bad challenger slashed |
| Ed25519 bypass | Neutron→Sepolia direction; Go verifies off-chain |
| Patricia ↔ IAVL transformation | Both directions |
| IApp dispatch pattern | BridgeMint + BridgeVault implement IApp |

## Sepolia → Neutron Flow

```
User (Sepolia)
  │
  ├─ tUSDC.approve(BridgeVault, amount)
  └─ BridgeVault.lock(amount, "pion-1", neutronRecipient)
       │
       └─ emits Locked(user, recipient, amount, nonce, destinationChainId)

Relayer (Go)
  │
  ├─ Observes Locked event
  ├─ EthereumPlugin.FetchProof(tx) → Patricia/Keccak proof
  ├─ VerifyConsensus (RPC trust — see Limitations)
  ├─ TranslateProofTo(Tendermint) → IAVL/SHA-256 proof
  └─ TendermintPlugin.SubmitMessage(envelope, transformedRoot, proof)
       │
       └─ Neutron: Verifier.submitMessage(...)
           → challenge window: 60s
           → Verifier.executeMessage(submissionId)
           → IApp(BridgeMint).onCrossChainMessage(...)
           → BridgeMint.mint(recipient, amount)

User (Neutron)
  └─ +amount tUSDC in Keplr wallet
```

---

## Neutron → Sepolia Flow

```
User (Neutron)
  └─ BridgeMint.burn(amount, "sepolia", sepoliaRecipient)
       └─ emits Burned(user, recipient, amount, nonce, destinationChainId)

Relayer (Go)
  │
  ├─ Observes Burned event
  ├─ TendermintPlugin.FetchProof(tx) → IAVL/SHA-256 proof
  ├─ VerifyConsensus → cometbft.NewValidatorSet.VerifyCommit()
  │    └─ validates 2/3+ Ed25519 validator signatures in Go
  ├─ TranslateProofTo(EVM) → Patricia/Keccak proof
  └─ EthereumPlugin.SubmitMessage(envelope, transformedRoot, proof)
       │
       └─ Sepolia: Verifier.submitMessage(...)
           → challenge window: 60s
           → Verifier.executeMessage(submissionId)
           → IApp(BridgeVault).onCrossChainMessage(...)
           → BridgeVault.release(recipient, amount)

User (Sepolia)
  └─ +amount tUSDC in MetaMask wallet
```
