# Tessera

Trust-minimized cross-chain framework. First reference application: a bidirectional `tUSDC` bridge between Sepolia (Ethereum testnet) and Neutron (Cosmos testnet, CosmWasm).

Built for the ChainGPT Let's AI Hackathon (May 7–9, 2026).
